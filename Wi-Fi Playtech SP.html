Conectar ao Wi-Fi Playtech SP

Baixe o instalador, extraia e dê dois cliques. O Windows salva a rede e conecta sozinho, sem digitar a senha.

Download

Rede
wifi-Playtech-SP
Segurança
WPA2-Personal (AES)
Arquivo
conectar_wifi.zip
Sistema
Windows 10 ou 11

Como usar

  1. Abra o conectar_wifi.zip baixado e clique em Extrair tudo.
  2. Dê dois cliques em conectar_wifi.bat.
  3. Se aparecer "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo.
  4. Aguarde alguns segundos. A janela mostra o estado da conexão. Pressione qualquer tecla para fechar.

A rede fica salva com conexão automática. Da próxima vez, o notebook conecta sozinho quando estiver no alcance.

O download não funcionou? Crie o arquivo manualmente
  1. Copie o código abaixo.
  2. Abra o Bloco de Notas e cole.
  3. Vá em Arquivo → Salvar como, escolha o tipo Todos os arquivos e salve como conectar_wifi.bat.
@echo off
setlocal
chcp 65001 >nul

set "SSID=wifi-Playtech-SP"
set "SENHA=xo11tzPlk4n4"
set "PERFIL=%TEMP%\wifi_perfil.xml"

echo Criando perfil da rede %SSID%...
(
echo ^<?xml version="1.0"?^>
echo ^<WLANProfile xmlns="http://www.microsoft.com/networking/WLAN/profile/v1"^>
echo   ^<name^>%SSID%^</name^>
echo   ^<SSIDConfig^>^<SSID^>^<name^>%SSID%^</name^>^</SSID^>^</SSIDConfig^>
echo   ^<connectionType^>ESS^</connectionType^>
echo   ^<connectionMode^>auto^</connectionMode^>
echo   ^<MSM^>^<security^>
echo     ^<authEncryption^>
echo       ^<authentication^>WPA2PSK^</authentication^>
echo       ^<encryption^>AES^</encryption^>
echo       ^<useOneX^>false^</useOneX^>
echo     ^</authEncryption^>
echo     ^<sharedKey^>
echo       ^<keyType^>passPhrase^</keyType^>
echo       ^<protected^>false^</protected^>
echo       ^<keyMaterial^>%SENHA%^</keyMaterial^>
echo     ^</sharedKey^>
echo   ^</security^>^</MSM^>
echo ^</WLANProfile^>
) > "%PERFIL%"

netsh wlan add profile filename="%PERFIL%" user=current
del /q "%PERFIL%"

echo Conectando...
netsh wlan connect name="%SSID%" ssid="%SSID%"

timeout /t 5 /nobreak >nul
netsh wlan show interfaces | findstr /i "SSID Estado State"

pause
endlocal
